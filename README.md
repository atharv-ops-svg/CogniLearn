# KnowVia

> Learn. Teach. Connect.

KnowVia is a skill-exchange platform designed to help people connect with others based on what they know and what they want to learn.

Instead of simply consuming educational content, KnowVia encourages people to **teach each other, learn from each other, and build connections through shared skills**.

---

## ✨ Features

### 👤 User Accounts

- Create a KnowVia account
- Secure username and password login
- Personal user profiles
- Store skills you know
- Store skills you want to learn

### 🔄 Skill Exchange

KnowVia connects the two sides of learning:

**KNOWS**

- Skills and subjects you can teach

**WANTS TO LEARN**

- Skills and subjects you want to learn

This creates the foundation for meaningful skill exchanges between users.

### 💬 Skill Exchange Chat

- Communicate with other users
- Discuss skills and learning goals
- Exchange knowledge directly

### 🤖 KV AI

KnowVia includes **KV AI**, an AI-powered learning assistant.

KV AI can:

- Explain concepts
- Help users learn new topics
- Connect existing skills with new learning goals
- Maintain conversation context
- Render Markdown responses

### 🧠 Persistent AI Conversations

KV AI conversations are stored separately from user information.

```text
knowvia.db
    ↓
Users and profiles

ai_chats.db
    ↓
KV AI conversations and messages
```
